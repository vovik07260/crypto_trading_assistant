# Crypto Trading Assistant

Проект для мониторинга криптовалютного рынка, формирования торговых сигналов и последующего применения методов искусственного интеллекта для поддержки принятия решений.

## Цели проекта

Разработать систему, которая позволяет:

- получать рыночные данные с биржи ByBit;
- отслеживать закрытие свечей на выбранных инструментах и таймфреймах;
- формировать уведомления по заданным торговым условиям;
- отправлять уведомления в мессенджер MAX;
- использовать LLM-модели для анализа рыночной ситуации и подготовки торговых рекомендаций;
- накапливать собственную историческую базу данных;
- исследовать и обучать модели машинного обучения для автоматизации торговых решений;
- в перспективе реализовать полностью автоматизированного торгового помощника.

## План развития

### Этап 1. Market Monitor
- Получение данных с ByBit.
- Контроль закрытия свечей.
- Проверка пользовательских условий.
- Отправка уведомлений.

### Этап 2. AI Analyst
- Интеграция с LLM.
- Формирование текстовых рекомендаций по сделкам.
- Анализ рыночной ситуации на основе последних данных.

### Этап 3. Data Warehouse
- Накопление исторических данных.
- Хранение сигналов и результатов сделок.
- Подготовка данных для обучения моделей.

### Этап 4. Machine Learning
- Исследование предиктивных моделей.
- Оценка качества прогнозов.
- Автоматизация генерации торговых сигналов.

### Этап 5. Automated Trading
- Интеграция с торговым API.
- Автоматическое выставление заявок.
- Контроль рисков и мониторинг результатов.
